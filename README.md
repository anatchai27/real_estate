# Real Estrad - Construction & Renovation Website

This is a Next.js project for a construction and renovation business.

## Tech Stack

-   **Framework:** Next.js (App Router)
-   **Language:** TypeScript
-   **Styling:** React Bootstrap (Bootstrap 5)
-   **Icons:** React Icons

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

-   `src/app`: App Router pages and layout.
-   `src/components`: Reusable UI components (HeroSection, ProjectCard, etc.).
